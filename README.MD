This is a discord bot that will help you and your community to issues daily challenges, track progress and display leaderboards.
It's using nodeJS

## Features
At first the app will support one type of challenge: daily pushup.

Here is the list of the uses cases:

1. Bot can be added to a channel in discord. This will create a new push up challenge for this community
2. The bot will post a link for the users to register with their discord account
3. Users will have the option to receive notification from the bot in discord to input the number of push up they did the current day
4. User will be able to interact with the bots and says how many push-up they did today
5. Once every user has submitted their number of push up or it becomes 5 PM the bot will publish today result
6. Every week and every month the bot will post a leaderboard with two column
  a. with the number of push up done
  b. with the number of check-in (a check-in is the number of day the user has submitted their number of push-up)
7. The user will be able to connect to an admin and see a calendar with their logged check-in
8. They will be able to correct mistake or add past values
9. They will have access to stats like: total amount of push-ups, last month vs this month and chart of over time


The user will be able to subscribe to many challenges in different servers, but if they have only one it will be auto-selected.
